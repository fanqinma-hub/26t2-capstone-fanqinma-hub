# Sprint 1 Integration, Privacy, QA and Demo Checklist

## Integration
- App shell can run locally.
- Main routes are defined.
- Folder ownership is clear.
- Role outputs can be connected through shared data contracts.

## Privacy
- No real child data is used.
- No raw audio is stored by default.
- Report avoids clinical diagnosis claims.

## QA
- Basic smoke test can open the app.
- Activity 1 voice flow can be reached and completed (press-and-hold to speak in Chrome web; tier result and reward shown).
- Error states and fallback paths are listed (browser mic unavailable, no speech heard, silence auto-advance, dev-only typed fallback).

## Demo
- Jira board is updated.
- GitHub repo has commits.
- Each role has visible Sprint 1 progress.
- Week 5 demo path is prepared.
